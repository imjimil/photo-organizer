# Opal — Product

## Register

product

## Users

One person with ~25k saved quote screenshots, literary passages, and mood images. They browse for feeling and search when a phrase or vibe returns.

## Product Purpose

Opal is a private inspiration library. It should feel like **a darkroom print table**: cool-slate by day, warm safelight at night, image-first, considered. Not a file manager. Not a dark developer tool.

## Brand Personality

Amber-lit, considered, alive. Quiet chrome, saturated photos.

## Anti-references

- Brown maison / Cartier clone from v4–v5
- Iridescent violet/mint glow from v6
- Left sidebar dashboard layout
- Generic AI dark mode (purple-blue gradients)
- Editorial-magazine ruled-metadata aesthetic
- OCR on thumbnails
- Training-data fonts (Inter, Instrument Sans, Fraunces, Newsreader, Cal Sans UI)

## Core flows

1. **Library** — full-width grid, collections strip, Recent / Shuffle
2. **Search** — open field, vibe discovery
3. **Viewer** — float-in image, pinch zoom, quote on intent
4. **Theme** — Light / Dark / Auto with smooth transition

## Accessibility

WCAG 2.1 AA. Reduced motion respected. Keyboard: `/` search, Escape viewer.
